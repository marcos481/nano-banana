# 🍌 Nano Banana — Ecossistema Criativo

Plataforma de inteligência artificial desenvolvida com Python, FastAPI e Next.js, reunindo ferramentas criativas e recursos de gerenciamento em uma interface web.

## 🚀 Tecnologias

- Python
- FastAPI e Uvicorn
- SQLAlchemy
- SQLite
- Next.js
- React e TypeScript

## 🧠 Funcionalidades

- Chat com inteligência artificial
- Estúdio gráfico para geração de imagens
- Histórico de imagens
- Dashboard
- Cadastro de clientes
- Gerenciamento de cardápio
- Consulta e atualização de pedidos de pizzaria

## 📁 Estrutura do projeto

- `backend/` — API, modelos e acesso ao banco de dados.
- `frontend/` — interface web.
- `documentos/` — documentação e manuais.
- `backups/` — cópias de segurança.
- `github/` — arquivos preparados para publicação.

## ⚙️ Execução local

O projeto foi desenvolvido para execução em ambiente local.

API, por padrão:
- Endereço local: `http://127.0.0.1:8002`
- Verificação de saúde: `http://127.0.0.1:8002/health`
- Documentação Swagger: `http://127.0.0.1:8002/docs`

Frontend, por padrão:
- Endereço local: `http://127.0.0.1:3001`

Para iniciar o projeto, confira as dependências e as instruções do script `iniciar-nano-banana.sh` antes de executá-lo. Se os serviços já estiverem rodando, não é necessário reiniciá-los.

## 🔒 Segurança

- Não publique senhas, tokens ou arquivos `.env`.
- Não envie bancos de dados com informações privadas.
- Não publique backups ou credenciais.
- Configure as variáveis de ambiente necessárias no seu próprio ambiente.
